- **Setup is much faster.** A new install takes about 8 to 10 minutes instead of 20 to 30. F7FIVE0 now brings its own copy of its database and of Python inside the install folder, instead of running their separate installers.
- Setup no longer asks for a password when the PC already has PostgreSQL. F7FIVE0 uses its own database and leaves the other one alone, so a silent or winget install works there too.
- If you already run F7FIVE0, updating keeps your database and settings exactly where they are. Nothing about your library changes.
- Uninstalling now also removes F7FIVE0's own database service. Your data stays in the data folder unless you choose to remove it.
