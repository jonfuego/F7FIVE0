- Installing with winget, or with Setup's silent switches, now finishes on its own. Setup no longer stops to ask for anything: open F7FIVE0 in a browser on the server PC afterwards and it asks you to create the admin account there.
- Setup downloads PostgreSQL and its service helper directly (fixed versions, checked before they run) instead of through winget, so it no longer hangs when winget started it.
- A silent install on a PC that already has PostgreSQL now says how to give it the PostgreSQL password, instead of stopping with a short error.
- Passwords are stored with a stronger method. Nothing to do: each account switches over the next time it signs in.
- On a new install, Setup asks whether F7FIVE0 may check GitHub for updates once a day. You can still check by hand in Admin > Updates.
- A new privacy page lists every outside service F7FIVE0 can contact and how to turn each one off. Setup shows it before installing.
- The web app's font now comes from your own server, not from the internet.
- Security fix for the web app (Next.js update).
